## 2024-07-11 - [CRITICAL] Prevent Hardcoded Password Fallbacks for Admin Actions
**Vulnerability:** A hardcoded password string (`'steveharrington'`) was used as a fallback for the complete system reboot function and for unlocking admin password changes. If the respective environment variables (`VITE_REBOOT_PASSWORD`, `VITE_ADMIN_PASSWORD_CHANGE_PHRASE`) were missing or not configured correctly, anyone who obtained the source code could easily deduce the hardcoded fallback password and execute critical administrative actions, leading to complete system compromise or data loss.
**Learning:** Environment variables designed for security and administrative actions should never fall back to hardcoded secrets. Using a fallback string in the source code completely nullifies the security benefit of using environment variables.
**Prevention:** Always rely strictly on the presence of the environment variable for security-sensitive operations. If an environment variable is missing, the application should "fail securely" (e.g., throwing an error or denying the action) rather than reverting to an insecure default.
