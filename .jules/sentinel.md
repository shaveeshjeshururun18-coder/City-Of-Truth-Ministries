## 2024-03-28 - [Hardcoded Secrets and Authentication Bypass]
**Vulnerability:** A hardcoded password string (`steveharrington`) was discovered being used as a default fallback for both `VITE_REBOOT_PASSWORD` (which allows complete deletion of Firestore and Storage data) in `services/api.ts` and `ADMIN_PASSWORD_CHANGE_PHRASE` (which allows bypassing/changing the admin dashboard password) in `components/AdminDashboard.tsx`.
**Learning:** Hardcoding default passwords as fallback strings when environment variables are missing creates a significant backdoor. Anyone who reads the source code can execute administrative actions without authorization if the environment variable happens to be undefined or is never set up properly in production.
**Prevention:** Always verify that necessary environment variables are defined. If a critical security-related environment variable is missing, the application should fail securely (deny access, log an error, or disable the feature) rather than falling back to a hardcoded string.
